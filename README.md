# Cloud Drive Danmaku Overlay

一个面向夸克网盘、百度网盘网页版的本地弹幕叠加插件 MVP。

## 已实现

- Manifest V3 Chrome/Edge 插件。
- 自动发现夸克网盘、百度网盘页面中的 `video` 播放器。
- 在播放器上方插入 Canvas 弹幕层。
- 同步播放、暂停、拖动进度条、倍速和全屏。
- 导入本地 `.xml`、`.ass`、`.json` 弹幕。
- 支持字号、透明度、速度、密度、时间偏移。
- 根据页面标题、文件名和视频时长生成缓存 key。
- 基础剧集识别：中文“第 N 集/话”和英文 `SxxEyy`。
- AI 区域支持填写剧名、季数、集数，用于生成/搜索剧情简介，再生成 AI 陪看弹幕。
- 导入后显示弹幕时间范围、当前播放时间和常见时间轴问题提示。
- 支持“测试当前”按钮，用于确认弹幕渲染层是否正常。
- 面板区分“未导入弹幕”“已导入 N 条”“缓存 N 条”“导入失败”。
- 支持粘贴 B 站链接、BV、av、ep 号导入弹幕。
- 支持连接本地 AI 服务，通过字幕或音频识别生成弹幕。
- 使用 `chrome.storage.local` 缓存当前视频弹幕和设置。

## 安装

1. 打开 Chrome/Edge 的扩展管理页面。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：`quark-danmaku-extension`。
5. 打开夸克网盘或百度网盘网页版并播放视频，点击右下角“弹”按钮。

## 支持站点

- 夸克网盘网页版
- 百度网盘网页版

第一版只适配网页版，不处理桌面客户端，也不接管账号登录。请先在浏览器中正常登录网盘并打开可播放的视频。

## AI 生成弹幕流程

AI 弹幕基于剧情简介生成，不是逐帧理解视频。推荐流程：

1. 点击右下角“弹”按钮。
2. 在 AI 生成区域填写剧名、季数、集数。
3. 点击“AI生成简介”或“剧情搜索”。
4. 检查并编辑剧情简介。
5. 点击“AI 生成弹幕”。

如果只填剧名，生成的是泛陪看弹幕；剧情简介越准确，弹幕越贴合。AI 草稿是全局草稿，不按剧集分别保存。切换到另一部剧时，可以直接修改剧名、季数、集数和简介。

## 从 B 站导入

1. 点击右下角“弹”按钮。
2. 在“B 站导入”里粘贴 B 站链接、`BV...`、`av...` 或番剧 `ep...`。
3. 点击“从 B 站导入”。

插件会请求 B 站公开接口解析 `aid/cid` 并导入弹幕。受限、付费、需要登录或接口拒绝的内容不会绕过限制，会直接显示错误。

## AI 生成弹幕

### 在线模型

不想启动本地服务时，可以直接在插件面板里配置在线模型：

1. 在“模型”里选择供应商。
2. 填写 API Key。
3. 填写模型名或接入点 ID。
4. 点击“保存模型配置”。
5. 输入剧情简介，或点击“国内搜索剧情”自动填充。
6. 点击“AI 生成弹幕”。

预设地址：

“AI生成简介”会直接调用当前在线模型配置，根据手动信息生成剧情简介。例如手动填写 `银魂 / 2 / 211` 时，会使用 `请生成《银魂》第二季第211集剧情简介` 作为提示。生成结果会填入剧情框，你可以修改后再点击“AI 生成弹幕”。

- 豆包/火山方舟：`https://ark.cn-beijing.volces.com/api/v3`
- DeepSeek：`https://api.deepseek.com`
- 通义千问：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- OpenAI：`https://api.openai.com/v1`

说明：

- 豆包/火山方舟的“模型名”通常填写你在控制台创建的模型接入点 ID。
- API Key 仅保存在当前浏览器扩展的本地存储里。
- 免费额度、模型名称和接口限制以各平台当前控制台为准。

### 本地服务

AI 功能需要启动本地服务：

```powershell
cd D:path\to\quark-danmaku-extension\local-ai-server
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
uvicorn server:app --host 127.0.0.1 --port 8765
```

编辑 `.env` 配置 OpenAI-compatible 接口：

```text
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_API_KEY=你的 API Key
OPENAI_MODEL=gpt-4o-mini
```

插件里可以：

- 可导入 `.srt/.ass/.vtt` 字幕，让 AI 基于字幕时间轴生成更贴合剧情的弹幕。
- 没有字幕时，可直接在剧情框粘贴剧情简介，或点击“AI生成简介”自动填入简介。
- 点击“AI生成简介”可直接调用已配置的在线模型生成剧情简介，再确认/编辑后生成弹幕。
- 可直接在插件里选择在线大模型并填写 OpenAI-compatible API 配置；本地 AI 服务变成可选。
- 在线模型生成不需要启动本地服务；音频识别相关代码仅作为高级能力保留，插件主界面不再展示。
- 插件入口只在检测到视频播放器时显示。
- AI 区域的剧名、季数、集数、剧情简介、风格、密度会自动保存为草稿，刷新或跳转播放页后恢复。
- AI 生成栏的密度控制生成目标数量：低/中/高约等于每分钟 2/4/8 条；播放设置里的密度滑杆控制实际显示比例。

音频识别需要额外安装：

```powershell
pip install faster-whisper
```

国内剧情搜索只读取公开短摘要，不抓字幕、台词、完整剧本或付费内容。百度百科如果触发限制会自动跳过，继续尝试其他来源。

## 弹幕很少或不出现

导入弹幕后，面板会显示：

- 弹幕总数
- 弹幕时间范围
- 当前播放时间
- 可能的时间轴提示

如果长时间看不到弹幕：

1. 点击“测试当前”。如果能看到测试弹幕，说明渲染层正常，问题通常是导入弹幕的时间轴不匹配。
2. 查看时间范围。如果当前播放时间早于第一条弹幕，需要继续播放或调整偏移。
3. 如果当前播放时间已经超过最后一条弹幕，需要回到前面或换正确的弹幕文件。
4. JSON 弹幕支持 `time`、`t`、`progress`、`stime`、`start` 字段；明显像毫秒的时间会自动转换为秒。
5. 如果面板显示“未导入弹幕”，说明当前版本还没有自动抓取平台弹幕，需要先手动导入 `.xml/.ass/.json`。

## JSON 弹幕格式

可以直接导入数组：

```json
[
  {
    "time": 12.5,
    "text": "这一段来了",
    "mode": "scroll",
    "color": "#ffffff",
    "size": 26
  }
]
```

也支持：

```json
{
  "comments": []
}
```

或：

```json
{
  "danmaku": []
}
```

## 合规边界

该 MVP 只做本地个人使用的弹幕叠加与本地文件导入。不要绕过平台登录、付费、加密接口或风控，也不要将第三方平台弹幕批量分发为公开弹幕库。
